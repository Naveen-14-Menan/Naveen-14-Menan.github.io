# Naveen Menan N S: Portfolio website

This repository contains my personal portfolio website.
The website is static. It uses only HTML, CSS and plain JavaScript.
GitHub Pages hosts the website from this repository.

Website URL: https://naveen-14-menan.github.io

## Files

| File | Purpose |
|---|---|
| `index.html` | The page content and structure |
| `style.css` | The design, light mode and dark mode |
| `script.js` | The theme button and the footer year |
| `favicon.svg` | The browser tab icon |
| `resume.pdf` | The resume that visitors download |

## Edit the content

1. Open `index.html`.
2. Find the section that you want to change. Each section starts with a comment, for example `<!-- WORK -->`.
3. Change the text.
4. Find each `[PLACEHOLDER]` and replace it with real data. Placeholders show with a yellow, dashed box on the page.
5. Save the file.
6. Open `index.html` in a browser to examine the change.

> **WARNING:** This repository is public. Do not add confidential employer data or a phone number.

## Replace the resume

1. Export the new resume as a PDF.
2. Name the file `resume.pdf`.
3. Upload the file to the root of this repository. Replace the old file.

## Publish with GitHub Pages

1. Put the files in a public repository with the name `Naveen-14-Menan.github.io`.
2. Go to **Settings > Pages**.
3. Set the source to **Deploy from a branch**.
4. Set the branch to `main` and the folder to `/ (root)`.
5. Save the settings.
6. Wait approximately 1 to 2 minutes. Then open the website URL.

> **NOTE:** GitHub can change these menu names. If a step is different, refer to the GitHub Pages documentation.

After the first setup, each push to the `main` branch updates the website.
